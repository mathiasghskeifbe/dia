Cómo reducir el peso de una foto sin ir a ciegas

Qué cambia al comprimir una imagen y cómo elegir entre JPG, PNG y WebP.

Todas las guías
IMÁGENES · 4 min de lectura · Equipo MFB Corporation

El peso y las dimensiones son cosas distintas

Las dimensiones indican cuántos píxeles tiene una imagen de ancho y de alto. El peso indica el espacio que ocupa el archivo. Dos fotos con las mismas dimensiones pueden tener pesos muy diferentes por su formato, calidad y contenido. Antes de cambiar algo, revisa qué límite te pide la plataforma donde vas a subirla.

Empieza por el tamaño que de verdad necesitas

Una imagen de 4.000 píxeles de ancho puede ser excesiva para una entrega que solo se verá en una pantalla pequeña. Reducir el ancho puede ahorrar mucho espacio. Conserva el original, mantén la proporción y prueba primero con una copia de 1.600 o 1.920 píxeles si se trata de una foto para ver en pantalla. No hay un tamaño ideal para todos los casos.

Elige el formato según el contenido

JPG suele ser práctico para fotografías y no conserva transparencias. PNG conserva transparencias y puede ser útil para capturas con texto o gráficos planos, aunque a veces pesa más. WebP admite transparencia y compresión con pérdida o sin pérdida; comprueba que el lugar donde subirás el archivo lo acepte.

Comprime, compara y decide

Prueba una calidad de 80 % como punto de partida. Revisa bordes, caras, letras pequeñas y degradados. Si notas manchas o detalles borrosos, sube la calidad. Si todavía pesa demasiado, reduce las dimensiones. Un archivo que ya está optimizado puede incluso aumentar de peso al volver a exportarlo.

Una forma sencilla de comprobar el resultado

Abre el original y el resultado con el mismo nivel de zoom. Confirma que las letras sigan siendo legibles y que el archivo cumpla el límite de subida. En MFB Corporation puedes ver el peso antes y después; tus imágenes se procesan en tu navegador y el original no se modifica.
