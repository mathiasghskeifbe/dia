ANTES DE SEGUIR

Lo que conviene saber.

¿Se sincroniza con mi teléfono?

No. Las tareas se guardan únicamente en el almacenamiento de este navegador y dispositivo. No hay cuenta ni sincronización.

¿Puedo perder mis tareas?

Sí, si borras los datos del navegador o usas una sesión privada. Descarga una copia si la información es importante. No uses esta herramienta para guardar datos sensibles.
