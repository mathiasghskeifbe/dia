Formatear JSON

Valida, da formato y compacta un documento JSON con mensajes de error claros.

LISTA PARA TI Procesamiento local
Los números muy largos pueden perder precisión en JavaScript. Usa cadenas para identificadores extensos.

Tus archivos y textos se procesan en este navegador, sin subirse a MFB Corporation.

ASÍ DE SENCILLO

Datos en orden.

Pasa de una cadena difícil de leer a un JSON ordenado. La herramienta valida la sintaxis antes de formatear y no ejecuta tu contenido.

  1. 1

    Pega un documento JSON válido.

  2. 2

    Elige formatear con sangría o compactar.

  3. 3

    Copia o descarga el resultado como archivo JSON.

ANTES DE SEGUIR

Lo que conviene saber.

¿Admite comentarios o comas al final?

No. Se usa el formato JSON estándar, que no permite comentarios ni comas después del último elemento.

¿Se conserva cada número con exactitud?

Se usa el analizador JSON de JavaScript. Los enteros que superen su rango seguro pueden cambiar. Representa identificadores muy largos como texto y evita usarlo para datos que requieran precisión especial.
