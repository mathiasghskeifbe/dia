ASÍ DE SENCILLO

El formato que te piden.

Cambia el formato de una imagen sin instalar programas. JPG funciona bien para fotos, PNG conserva transparencias y WebP ofrece una alternativa moderna.

  1. 1

    Selecciona una imagen JPG, PNG o WebP.

  2. 2

    Elige el formato de salida y la calidad cuando corresponda.

  3. 3

    Descarga el archivo convertido.

ANTES DE SEGUIR

Lo que conviene saber.

¿Puedo convertir HEIC, SVG o un GIF animado?

Esta versión acepta JPG, PNG y WebP. No admite HEIC o SVG, ni conserva animaciones.

¿Qué pasa con la transparencia?

PNG y WebP pueden conservarla. JPG no admite transparencia y se usa un fondo blanco al exportar.
