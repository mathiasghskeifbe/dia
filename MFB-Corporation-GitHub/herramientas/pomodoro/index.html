ANTES DE SEGUIR

Lo que conviene saber.

¿Funciona si cierro la pestaña?

Debes mantener la pestaña abierta. Si el navegador la suspende, el reloj se corrige al volver. No se garantiza un aviso mientras el dispositivo está bloqueado.

¿Tengo que usar exactamente 25 minutos?

No. Puedes ajustar la duración de cada sesión. Usa bloques que se adapten a tu tarea y a tu tiempo disponible.
